# Roadmap - Tiệm Bách Hoá Hai Tụi Mình

## Vision
To build the most polished e-commerce frontend in the region, focusing on extreme performance and user experience.

## Strategic Phases

### Phase 1 — Foundation Setup (Completed)
- FSD Architecture
- Core dependencies & configuration
- Next-gen infra preparation

### Phase 2 — Design System (Completed)
- Semantic HSL color system
- Typography system
- Theme Store (Zustand)

### Phase 3 — Interactive Core Systems (Completed)
- ShadCN UI Initialization
- Global Layout & Navigation
- Interactive UI primitives
- Cart interaction system

### Phase 4 — Commerce Experience (Completed)
- **4A Commerce Engine:** Order, Payment, Checkout Flow
- **4B Shipping Engine:** Dynamic calculation, Provider abstraction
- **4C Tracking Experience:** Post-order tracking & Live Map
- **4D Product Detail Experience:** High-fidelity PDP & Variant sync
- **4E Search & Discovery:** Multi-modal search & Filter system

## Phase 5 — Hardening & Stabilization (Completed)
- **5A Motion & UX Polish:** Premium micro-interactions
- **5B Interaction Stabilization:** Regression prevention & State hardening
- **5C Performance Hardening:** Rerender audits & Memoization
- **5D Accessibility & QA Hardening:** WCAG AA compliance & Visual Snapshots

### Phase 6 — Advanced Search & Discovery (Completed)
- Predictive Intent Ranking
- Thumb-zone optimized search UI
- Persistent URL-based filter state

### Phase 7 — Admin Engine & Operations (Completed)
- Batch order mutations
- Robust product validation
- Order detail accessibility

### Phase 9 — Production Scaling (Next)
- Backend optimization
- Real production data layer
- **Q2 2026:** Core E-commerce Flow & Tracking Experience (Completed)
- **Q3 2026:** Performance Optimization & Accessibility Compliance
- **Q4 2026:** AI-driven Personalization & Visual Search
